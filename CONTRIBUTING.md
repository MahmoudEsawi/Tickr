# 🤝 Contributing to Tickr

Thank you for your interest in contributing to **Tickr for Mac**!

---

## 🛠️ Development & Building

### 1. Prerequisites
- macOS 13+
- Swift 5.9+ / Swift 6.0 (`swift --version`)

### 2. Running Locally
```bash
git clone https://github.com/MahmoudEsawi/Tickr.git
cd Tickr
swift run
```

### 3. Submitting Pull Requests
1. Fork the repo and create a feature branch (`git checkout -b feat/my-feature`).
2. Implement your changes in `Sources/Tickr/`.
3. Test locally using `swift run`.
4. Commit using Conventional Commits and submit a PR!
